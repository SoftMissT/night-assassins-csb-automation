# Artes verticais das armas

Coloque neste diretório as ilustrações 9:16 usadas como arte expandida dos Items de arma.

## Formato recomendado

- Proporção: `9:16`
- Resolução: `1080x1920`
- Formato: `.webp`
- Nome: minúsculo, sem acentos e separado por hífens

Exemplo:

```text
rebellion.webp
gae-bolg-espinho-do-destino-selado.webp
boosted-gear.webp
```

No campo `arma_imagem_vertical`, use o caminho distribuído pelo módulo:

```text
modules/night-assassins-csb-automation/assets/weapons/vertical/rebellion.webp
```

A propriedade nativa `img` do Item continua reservada para a imagem quadrada 1:1 exibida no inventário e no Compendium.
